# 📄 AI Resume Screening System

An AI/ML based Resume Screening System that uses Natural Language Processing and Machine Learning to analyze resumes and predict suitable job categories.

## 🚀 Features

- Upload resume in PDF format
- Extract text from resume
- NLP-based text processing
- TF-IDF feature extraction
- Machine Learning classification
- Job category prediction
- Prediction confidence
- Simple Streamlit web interface

## 🧠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- TF-IDF
- Logistic Regression
- Streamlit
- PyPDF2

## 📊 Job Categories

The system can classify resumes into categories such as:

- Data Science
- AI/ML
- Software Engineering
- Web Development
- Cybersecurity
- Database

## ⚙️ Machine Learning Workflow

Resume PDF
↓
Text Extraction
↓
Text Preprocessing
↓
TF-IDF Vectorization
↓
Logistic Regression
↓
Job Category Prediction

## 💻 How to Run

Clone the repository:

git clone YOUR_REPOSITORY_URL

Install dependencies:

pip install -r requirements.txt

Train the model:

python train_model.py

Run the application:

streamlit run app.py
